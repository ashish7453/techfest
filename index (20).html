Three rounds, one signal path

Each round removes something you'd normally be given — first the derivation, then the problem statement, then the schematic itself.

01
20 min · elimination

Decode the table

Given a 3–4 input truth table, derive the simplified Boolean expression via K-map and name the minimum gates required. Fastest correct answers advance.

02
40 min · core round

Build the logic

You're handed a real-world scenario, not a table — a staircase switch, a majority-vote sensor, a safety interlock. Build the truth table yourself, then implement it on breadboard or simulator.

03
20 min · finale

Reverse engineer

A working black-box circuit, inputs and outputs only. Probe it, reconstruct its truth table, and name the function. First correct identification wins the event.
